# SpatialReal Python SDK — project instructions

`spatialreal`: realtime avatar sessions over the driven-ingress v2 WebSocket. Successor to the
retired `avatarkit` package (same wire protocol). See `README.md` for usage.

## Development

```bash
uv venv && uv pip install -e ".[dev]"
python -m pytest tests -q     # protocol-level tests against an in-process fake backend
```

## Generated code

`spatialreal/proto/generated/` is generated code: never edit it by hand, and never add `.proto`
files to this repository. It is regenerated by `.github/workflows/protobuf-codegen.yml`; if
Actions is down, run that workflow's Generate step by hand with the dev extra installed.
